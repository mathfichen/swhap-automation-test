# Negative / positive archive fixture corpus (crit-M6 / crit-M3)

Deterministic generator scripts + a pinned sha256 manifest — **no committed
binaries** (core-pipeline.md §6.2). The validator workstream mounts this as its
`fixtures/negative/` admission-test set (M1a); core runs it as the full
hardening battery at the M2 entry gate.

## Layout

| Path | Role |
|---|---|
| `build.py` | the generator (and `--check` reproducibility gate) |
| `MANIFEST.sha256` | pinned sha256 of every archive (`sha256sum` format) |
| `index.json` | machine-readable register: per-fixture isolated property, disposition, expected error code, crit reference |
| `archives/` | the materialized fixtures (regenerated by `build.py`; git-ignorable) |

```sh
python build.py          # (re)materialize archives/ + MANIFEST.sha256 + index.json
python build.py --check  # rebuild into a temp dir, verify bytes == MANIFEST (CI gate)
```

## Determinism

Every tar member's mtime is set explicitly (never the wall clock); uid/gid = 0,
uname/gname = ""; members emitted in a fixed order; GNU tar format throughout;
gzip via `gzip.compress(..., mtime=0)`. A rebuild on any machine reproduces the
pinned MANIFEST byte-for-byte (proved by `--check` and the pytest suite).

## Fixtures — one isolated property each

`neg-*` MUST be **rejected** with the named error code; `pos-*` (and the two
`ACCEPT` `neg-*`) MUST be handled **without losing bytes**.

| Fixture | Isolated property | Disposition | Code | crit |
|---|---|---|---|---|
| `neg-traversal-dotdot.tar` | `..` path component | REJECT | `EX-TRAVERSAL` | M6 |
| `neg-absolute-path.tar` | absolute member path | REJECT | `EX-ABS` | M6 |
| `neg-symlink-escape.tar` | symlink → absolute path off-root | REJECT | `EX-SYMLINK-ESCAPE` | M6 |
| `neg-symlink-rel-escape.tar` | symlink → relative path escaping root | REJECT | `EX-SYMLINK-ESCAPE` | M6 |
| `neg-hardlink-outside.tar` | hardlink target outside member set | REJECT | `EX-HARDLINK-OUT` | M6 |
| `neg-device-fifo.tar` | FIFO / special member | REJECT | `EX-DEVICE` | M6 |
| `neg-duplicate-member.tar` | duplicate path, differing content | REJECT | `EX-DUP` | M6 |
| `neg-case-collision.tar` | casefold-equal paths (`README`/`readme`) | REJECT | `EX-CASE-COLLISION` | M6 |
| `neg-non-utf8-name.tar` | non-UTF-8 filename bytes (`b"caf\xe9.txt"`) | ACCEPT (bytes preserved, encoding journaled) | — | M6 |
| `neg-bomb-ratio.tgz` | decompression-bomb ratio (only the ratio trips) | REJECT | `BG-RATIO` | M6 |
| `pos-bom-crlf.tar` | UTF-8 BOM + CRLF text | ACCEPT (verbatim) | — | M6 |
| `pos-dotfile-root.tar` | dotfile at root (dt2sg glob-loss) | ACCEPT (preserved) | — | M3 |
| `pos-wrapper-dir.tar` | single wrapper directory | ACCEPT (stripped) | — | M6 |
| `pos-emptydir.tar` | empty directory | ACCEPT (`.emptydir`) | — | M6 |
| `pos-pre1970-mtime.tar` | pre-1970 (negative-epoch) mtime | ACCEPT (raw `@<epoch>`) | — | M3 |

The error codes match the core extraction-contract taxonomy
(`core-pipeline.md` §5: `EX-*`, `BG-*`). `index.json` is the authoritative
machine-readable form; this table is the human view.
